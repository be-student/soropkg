# soropkg

**soropkg** is on-chain interface tooling for [Soroban](https://developers.stellar.org/docs/build/smart-contracts/overview) smart contracts on Stellar. It reads a deployed contract's interface directly from the chain, and watches the contracts your app depends on for **breaking upgrades**.

```bash
npm install -g soropkg
```

---

## Why soropkg?

Soroban stores each contract's interface spec directly inside its deployed WASM binary on-chain (`contractspecv0`). soropkg reads that spec straight from the network — no separate ABI files to manage or keep in sync.

- **No ABI files.** Contract interfaces live on-chain. soropkg reads them directly.
- **Interface diffing.** Compare a contract's interface between two WASM versions and classify every change as breaking or non-breaking.
- **Drift monitoring.** Soroban contracts can upgrade in place, silently changing their interface. `soropkg check` snapshots the contracts you depend on and fails your CI when one upgrades in a breaking way.

---

## Quick example

```bash
# Inspect any live contract's interface
soropkg inspect CAQQR5SWBXKIGZKPBZDH3KM5GQ5G...

# Scaffold a project manifest
soropkg init

# Diff a contract's interface between two WASM versions
soropkg diff <contract-id> <old-wasm-hash> <new-wasm-hash>

# Watch your dependencies for breaking upgrades (in CI)
soropkg check
```
