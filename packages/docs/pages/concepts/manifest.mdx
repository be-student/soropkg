# soroban.toml

`soroban.toml` is the project manifest scaffolded by [`soropkg init`](/cli/init) — a place to declare your package metadata and deployed contract addresses per network. It lives in the root of your project directory.

<Callout type="info">
  Monitoring the contracts you *depend on* uses a separate file, [`soroban-watch.toml`](/cli/check) — see `soropkg check`.
</Callout>

---

## Full example

```toml filename="soroban.toml"
[package]
name        = "my-org/my-protocol"
version     = "1.0.0"
description = "A brief description of what this protocol does"
license     = "Apache-2.0"
repository  = "https://github.com/my-org/my-protocol"
homepage    = "https://my-protocol.xyz"
keywords    = ["defi", "lending"]

[networks.mainnet]
vault = "CCVAULTMAINNET..."
pool  = "CCPOOLMAINNET..."

[networks.testnet]
vault = "CCVAULTTESTNET..."
pool  = "CCPOOLTESTNET..."
```

---

## `[package]`

| Field | Required | Description |
|---|---|---|
| `name` | Yes | `org/name` identifier for your package |
| `version` | Yes | Semver version string |
| `description` | No | Short description |
| `license` | No | SPDX license identifier |
| `repository` | No | Source repository URL |
| `homepage` | No | Project website |
| `keywords` | No | Array of tags |

---

## `[networks.<network>]`

Declare your deployed contract addresses per network. Keys are arbitrary and represent the contracts in your project. Values are `C...` Stellar contract addresses.

```toml
[networks.mainnet]
vault = "CCVAULTMAINNET..."
pool  = "CCPOOLMAINNET..."
```

Supported networks: `mainnet`, `testnet`, `futurenet`.
