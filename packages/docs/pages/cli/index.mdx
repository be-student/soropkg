# CLI Reference

soropkg is a command-line tool. All commands follow the pattern:

```bash
soropkg <command> [arguments] [options]
```

---

## Commands

| Command | Description |
|---|---|
| [`inspect`](/cli/inspect) | Read the interface of a deployed contract from the chain |
| [`init`](/cli/init) | Scaffold a `soroban.toml` manifest |
| [`diff`](/cli/diff) | Diff a contract's interface between two WASM versions |
| [`check`](/cli/check) | Watch declared contracts for interface drift |

---

## Common options

Most commands that query the chain accept:

| Option | Description |
|---|---|
| `-n, --network <network>` | `mainnet` (default), `testnet`, or `futurenet` |
| `--rpc <url>` | Use a custom RPC endpoint instead of the default public one |
| `--json` | Output machine-readable JSON |
| `-h, --help` | Show help for the command |

Run `soropkg --help` or `soropkg <command> --help` at any time for the authoritative list.
